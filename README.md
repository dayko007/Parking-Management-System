# Parking Management System

## Project Description

The Parking Management System is a C# Object-Oriented Programming project that manages parking spaces, vehicles, parking tickets, and parking fees.

## Objectives

* Manage parking space availability.
* Register vehicles entering the parking lot.
* Generate parking tickets.
* Calculate parking duration and fees.
* Release parking spaces when vehicles leave.
* Handle basic errors, such as a full parking lot and invalid tickets.

## Classes

1. **Vehicle** — Stores vehicle information.
2. **ParkingSpace** — Manages parking space availability.
3. **ParkingTicket** — Records parking entry and exit times.
4. **ParkingLot** — Manages parking spaces and active tickets.
5. **ParkingFeeCalculator** — Calculates parking fees.
